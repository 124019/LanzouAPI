# 简洁，高效的蓝奏云API
---
## 设计理念
---
- 轻，快，好——  **Python** 版本本体与**JavaScript** 版本编译前只有大约 **10kB**
- 无需注册，无需登录，无需任何限制。输入密码，直链以及文件格式，获取你的URL
- 无需任何第三方包依赖[^1]
[^1]:暂时只有Node.js可实现。

## 开源许可协议
---
本项目现已采用 **GNU LGPL v2.1** 许可证，公开并免费使用。
- **根据规定，从你开始使用本程序开始则默认认可并遵循此项目的全部条款**

## 全部版本[^2]

---
- **JavaScript** 版本(调用示例参见 `example.js` )
- **Python** 版本(调用示例参见 `example.py` )
- **Kotlin** 版本(该版本由 [R3n_011](https://github.com/r3n011) 负责转译与长期维护)
[^2]:这几个版本有时可能并不是同步更新的，并且一些细微的实现并不是相同的，请留意版本差异。(尤其是py和js版本)

## JavaScript 版本运行环境：

---
- Node.js 24+[^3]
- ~~QuickJS~~(因为调用了`fetch()`以及使用了非标准的`res.headers.raw()`)
[^3]:Node.js 24以下的版本尚未测试，可能存在不兼容，请自行测试。
