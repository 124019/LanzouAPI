# 简洁，高效的第三方蓝奏云下载API

## 设计理念

- 轻，快，好——  **Python** 版本本体与**JavaScript** 版本编译前只有大约 **10kB**
- 无需注册，无需登录，没有任何限制。输入密码，直链以及文件格式，获取你的URL
- 无需任何第三方包依赖[^1]


## 开源许可协议

本项目现已采用 **GNU LGPL v2.1** 许可证，公开并免费使用。


## 全部版本[^2]

- **Python** 版本(调用示例参见 `example.py` ) `Python 3.11`
